#  Ticket Booking System

A simple **Ticket Booking Application** that allows users to book, view, and manage tickets locally.  
This project demonstrates core concepts of Java such as **OOP, file handling, and user interaction** — and can be run directly without any external setup.

---

## Features
- Book tickets for available events or shows  
- View booked tickets and details  
- Cancel tickets  
- Stores data locally (no database needed)  
- Simple command-line interface or GUI (if applicable)

---

## Tech Stack
- **Language:** Java  
- **IDE (Optional):** IntelliJ / VS Code  
- **Data Storage:** Local file system
